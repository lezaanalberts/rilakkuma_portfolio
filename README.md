# Rilakkuma Portfolio
This project is a cute portfolio done to practice some skills. This is a passion project, so no real problems are solved here.

## Getting Started
* clone this repo [here](https://github.com/lezaanalberts/rilakkuma_portfolio)

* run **npm install** to install all dependencies

### prerequisites
* have [Node.js and npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm/) installed
